# TataramonTech Frontend (UI/UX)

## 🎨 Overview

This repository contains the **frontend UI/UX implementation** of TataramonTech — a language translation and learning tool focused on English ↔ Bikol translation. The frontend emphasizes clarity, accessibility, and an intuitive user experience, while visually presenting linguistic insights such as Parts of Speech (POS) tagging.

## 🧭 Design Goals

* **Clarity:** Make translations easy to read and understand
* **Guided Interaction:** Smooth flow from input → translation → insights
* **Educational Value:** Highlight POS tagging without overwhelming users
* **Consistency:** Cohesive layout, typography, and color usage
* **Responsiveness:** Works across different screen sizes

## ✨ Key UI/UX Features

* 🔤 **Translation Interface**

  * Clean input field for English/Bikol text
  * Clear call-to-action button (e.g., *Analyze / Translate*)

* 📊 **POS Tagging Visualization**

  * Displays parts of speech for both source and translated text
  * Structured breakdown for easier understanding

* 📜 **History Screen**

  * Stores previous translations
  * Retains POS tagging data for each entry

* 🧩 **Modular Layout**

  * Sections divided into Input, Output, and Analysis
  * Improves readability and user focus

* 🎯 **Improved Navigation**

  * Logical page flow (Home → Translate → Results → History)

## 🧱 UI Structure

* **Home / Landing Section**

  * Brief introduction
  * CTA button to start translation

**Translation Section**

  * Input field
  * Translate/Analyze button

* **Results Section**

  * Translated output
  * POS tags and breakdown

* **History Section**

  * List of past translations with details

## 🎨 Design System

* **Typography:** Simple, readable fonts for accessibility
* **Color Scheme:** Minimal with accent color for actions and highlights
* **Components:** Buttons, cards, input fields, and data containers
* **Spacing:** Consistent padding and margins for clean layout
